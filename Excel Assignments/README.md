# Excel Assignments

This folder contains Excel assignments completed as part of the **AI-Driven Data Analytics Program at Entri**.

The assignments focus on developing practical data analysis skills using Microsoft Excel.

### Topics Covered
- Data Exploration and Understanding
- Data Cleaning and Transformation
- Data Sorting and Filtering
- Excel Formulas and Functions
- Data Analysis and Interpretation
- Data Visualization

### Objective
To develop hands-on experience in working with datasets, identifying patterns, cleaning raw data, and extracting meaningful insights using Excel.
