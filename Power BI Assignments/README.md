# Power BI Assignments

This folder contains Power BI assignments and projects completed as part of the **AI-Driven Data Analytics Program at Entri**.

The projects focus on transforming raw data into meaningful insights through interactive dashboards and visualizations.

### Topics Covered
- Data Import and Transformation
- Power Query
- Data Modelling
- DAX (Data Analysis Expressions)
- Data Visualization
- Interactive Dashboards and Reports
- Business Insights and Reporting

### Objective
To develop practical skills in building interactive dashboards, analysing data, and communicating insights to support data-driven decision-making.
